Outils IA personnels

Politique de confidentialité

Cette politique concerne uniquement la configuration privée « Outils IA personnels », administrée par Rogue06.

Dernière mise à jour : 20 octobre 2026.

Données utilisées et finalités

La configuration peut accéder aux fichiers Drive, documents Docs, feuilles de calcul Sheets, messages Gmail, listes d’agendas et événements du compte autorisé. L’adresse e-mail et les informations de profil identifient ce compte. Ces données servent exclusivement aux tâches personnelles demandées par le propriétaire : recherche, organisation, rédaction et modification de ses contenus.

Fonctionnement et destinataires

Google Workspace CLI utilise les autorisations du propriétaire pour appeler les API Google. Lorsqu’une tâche est confiée à Claude Code ou Codex, les données nécessaires à cette tâche peuvent être transmises respectivement à Anthropic ou OpenAI et traitées selon les conditions et paramètres du compte utilisé. Le traitement n’est donc pas exclusivement local.

Cette configuration ne prévoit aucune vente de données ni utilisation publicitaire. Les données Google sont utilisées pour fournir les fonctionnalités demandées, conformément aux règles Google sur les données utilisateur, notamment leurs exigences d’utilisation limitée.

Stockage et conservation

Les identifiants de connexion de gws sont stockés sous forme chiffrée sur l’ordinateur du propriétaire. Aucun identifiant, message, document ni événement Google n’est publié sur ce site ou dans son dépôt de code.

Les résultats téléchargés ou enregistrés sont conservés aux emplacements choisis par le propriétaire jusqu’à leur suppression. Les conversations des assistants peuvent contenir des résultats de tâches ; leur conservation dépend des réglages et politiques du service utilisé.

Révoquer l’accès et supprimer les données

Le propriétaire peut révoquer l’accès via les connexions tierces de son compte Google, déconnecter gws, supprimer les fichiers locaux concernés et gérer les conversations dans ses comptes d’assistants. La révocation ne supprime pas automatiquement les documents ou messages déjà créés, ni leurs copies.

Visite de cette page

Ce site statique n’utilise aucun formulaire, script de suivi, cookie applicatif ou accès Google. Il est hébergé sur GitHub Pages. GitHub peut conserver des informations techniques, notamment l’adresse IP, pour la sécurité du service, conformément à sa politique de confidentialité.

Responsable et contact

Responsable : Rogue06. Pour une question sur cette page, un ticket peut être ouvert dans le dépôt dédié. Les tickets étant publics, ne pas y inscrire de données personnelles, identifiants ou contenu Google.
